# Prompt 06 — Deployment and Team Handoff (Codex)

Prepare the approved TerraTwin application for deployment and team handoff.

1. Inspect the existing Vite deployment configuration and choose the simplest supported static deployment path.
2. Do not expose secrets, credentials, Earth Engine tokens, or private files.
3. Confirm that only compact browser-ready JSON is published under `public/data/`.
4. Run the final build and all available tests.
5. Verify the deployed app at desktop and 390 px mobile sizes.
6. Confirm the final Figma design has been followed.
7. Update README with prerequisites, install/run/build commands, data pipeline instructions, source limitations, and deployment steps.
8. Add a short AI-tool disclosure: Codex used for backend/data/scoring and frontend where available; Antigravity used for frontend only if the Plan B fallback was activated.
9. Provide a concise demo walkthrough and list the strongest evidence-backed project findings.
10. List all remaining limitations honestly.

Never claim a dataset, test, deployment, or feature is complete unless it has actually been verified.
